
# Laboratório de Senhas

**Autora:** lissaxwz

## Sobre o projeto

Este repositório faz parte de uma atividade de laboratório de senhas.

## Objetivo

Estudar conceitos de segurança de senhas, criação de senhas fortes e boas práticas para proteger contas digitais.

## Boas práticas

- Utilizar senhas longas e difíceis de adivinhar.
- Evitar informações pessoais nas senhas.
- Não reutilizar a mesma senha em várias contas.
- Ativar a autenticação em dois fatores quando disponível.
